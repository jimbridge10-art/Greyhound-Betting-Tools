# Greyhound-Betting-Tools
Premium landing page for Greyhound Betting Software Suite, featuring responsive design, core tool showcases, and integrated checkout hooks.
READ ME FIRST
This folder contains a set of three stand-alone Windows applications (.exe) designed for greyhound racing analysis and performance evaluation. The three are also available together in a single Greyhound Pack.
The Selector is used to produce a rating for each runner in a selected race, based on manually entered inputs. The Split Predictor is used to analyse early race positioning at the first bend. Compare Tracks is used to compare performance across different tracks. The Greyhound Pack brings all three tools together in one package.
To begin, open the relevant product folder (Selector, Split Predictor, Compare Tracks, or Greyhound Pack) and run the application by double-clicking the .exe file. If Windows displays a security warning, select “More info” and then “Run anyway” to proceed. If the application does not save data correctly, right-click the executable and choose “Run as administrator.”
Each product includes tutorial files that explain the logic and calculations used within the tools. These are provided to help users understand how each application generates its results and selections.
It is important that the executable files remain in their original folders, as they rely on the surrounding directory structure to function correctly. Any data generated or saved should be stored within the appropriate product folder to ensure the system remains fully synchronised.
